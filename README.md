# english-words

命令行背单词工具，Python 写的，数据存本地 JSON。

## 功能

- 加词：输入单词和释义，存进词库
- 查词：输入单词，显示释义
- 删词：输入单词，从词库移除
- 列全部：显示词库所有词条
- 抽考：随机抽一个词，让你回忆释义

## 运行

需要 Python 3.10 以上，无第三方依赖。

```bash
git clone <仓库地址>
cd english-words
python main.py
```

第一次运行会自动创建 `words.json`。

## 数据格式

`words.json` 是一个字典，键是单词，值是释义：

```json
{
  "apple": "苹果",
  "banana": "香蕉"
}
```

想批量导入，直接编辑这个文件。
